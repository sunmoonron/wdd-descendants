# 55. The forecast against the feature route, and the planted row (S125)

**Question.** Session 124's review left the recruitment law's parameter-level parts as the program's own: which row is recruited, forecast ahead, by what. Does a learned feature dictionary on the same checkpoints forecast the same recruits, and can it name the parameter? And does the nearest-row law hold as a causal prediction when a row is planted near a class whose speaker has been removed?

**Established.**
- On Pythia-160m the class-side score forecasts recruitment two checkpoints ahead at AUC 0.886 (seed 0, block 6; seeds 1 and 2 0.884 and 0.881, block 9 0.923), against the row's own S 0.869, the learned dictionary's routes to a parameter at 0.810 (largest decoder cosine), 0.772 (feature mass) and 0.915 (the class-side score with the autoencoder's active sets as the partition), the generic alignment with the cloud at 0.860, the row's own OMP usage at t, the autocorrelation baseline that wordhood is defined by, at 0.923 (seeds 1 and 2 0.917 / 0.922, block 9 0.953; in e588 it was 0.964 on Pythia-410m and 0.968 on OLMo-1B against the class side's 0.927 / 0.932, a comparison the paper's sentence left out), the rotated dictionary's own class-side forecast at 0.806, the static step-1000 score at 0.640 and a label shuffle at 0.501; combined leave-one-checkpoint-out, S with the class-side score 0.869, the three feature-side scores 0.919, both 0.910, everything 0.953; retrodiction two checkpoints back 0.897 (e629).
