Act 1 · Qwen2.5-0.5B

Find the gender and number rows, and flip them in the weights

The items are few-shot translations into English ("French: reine → English: ___") in French, Spanish and German. Rows are chosen on three templates; translation effects are measured on two held-out templates, free text on separate sentences. No probe, no autoencoder, no gradient steps.

Act 2 · Qwen2.5-Coder-0.5B-Instruct

The same addresses in a different model

Same architecture, continued-pretrained on code (5.5T tokens per the Qwen2.5-Coder report) and instruction-tuned. The base model's row addresses and residual direction are applied without running a single Coder prompt to choose them; the Coder model's own rows and direction are shown for comparison. Needs Act 1's scan; the first run loads the model (about half a minute).

Act 3 · Pythia-410m

Tamper with one row, then audit the model blind

Someone edits one block-4 write row in place. The auditor gets only the tampered weights and 16 ordinary wikitext windows: no original checkpoint, no diff. Three detectors: the column's norm (z-score above 3), the read-write cosine (above the block's 99th percentile), and activation consistency (does the write agree with the states where its neuron fires, minus its own write; below the 1st percentile), all computed on the tampered model itself.
